## 按失败路径设计新作品

公共 pet-kit **0.3.0** 已将运动呈现时间线抽成可选 Motion，见 [公开调用与适配](pet-kit.md#030可选的远端-motion-显示缓冲)。新作品优先复用其缓存/插值基础，保留作品的原始位置时间、字段/边界和生命周期适配，不照抄旧游戏的独立缓冲。它不自动处理本地预测、裁判、断线或旧代拒收，仍执行下面的失败路径和完整玩法验收；原案例提交保留为根因证据。

### 本地操作、权威规则与绘制校正分开

房主继续裁定碰撞、伤害、计时和胜负。本地按键可立即预测；权威快照校正后的规则状态必须正确，平滑坐标只用于绘制，不能写回物理世界、命中范围或输入。

客人的自身角色与客人看到的远端角色采用各自策略。自身角色不直接套远端插值延迟，否则按键会变迟；小误差可在独立绘制层平滑，转向/跳跃仍及时响应。死亡、重生、抓取、瞬移、新局等明确断点应重置，不能画成穿过地图的移动。预测偶尔让出一帧等待权威追上时，检查绘制误差收敛是否造成反向一步。角色在移动平台上时，要核对脚底与平台使用兼容的呈现时钟。

远端轨迹按快照的权威 frame/t 排序，不按各包本机收到时间直接连线；权威时钟到本机渲染时钟的映射、缓存时间和外推上限须有明确策略。重复/迟到快照不倒退呈现时间，长时间缺包停止外推并显示恢复状态。切局/赛道/阶段/座位、新 epoch、暂停恢复与关闭，分别定义旧轨迹的清理/重建条件。

赛车快照采用 150 ms 缓冲、最多 100 ms 外推；大乱斗本地修复采用 100 ms 误差衰减尺度和 12 游戏单位重置边界。这些是各自作品的已验证参数，**不能直接当新游戏默认值**；根据玩法速度、碰撞与实测时延确定，并报告原阈值。

### ACK 不作为模拟时钟

区分消息接收确认、输入已执行确认和状态已应用确认。不能拿“还剩几个未 ACK 输入”推算预测世界应该在哪一帧，也不能因为权威帧已超过计划帧就丢掉仍在途的攻击。保留有界的输入序列与执行计数，按确定规则重放/追赶；一个实际按键只执行一次，旧局消息不能启动新局。ACK/缓存丢失与新 epoch 要有完整状态恢复路径。

### 形象资源与会话状态分别恢复

资源以实际已验证数据及签名识别，不以同名、座位当前占位角色或“收到 hello 才能收图”的顺序假设识别。形象先到时有界暂存，身份声明匹配后接纳；不把尚未匹配的数据当成已认证身份转发。支持中途加入/观战的作品要让后来者获得已有资源，也让已有玩家收到后来者的资源。

成功传过的资源，不因同一会话的新 epoch/resync 自动重传整套。签名变更、收件人确实缺失或新会话需要时，才按明确策略有限补发。限制待确认缓存、排队与重试，传输串行/背压时留出操作与状态消息预算。旧提交中的 8 MiB 是当时桥接预算的依据，不是可硬编码的通用 SDK 保证；按目标宿主的实际限额验收。

### 恢复后重新评估可开局条件

在线状态、素材完成、准备意图可能按不同顺序到达。分别更新后都应检查同局可开始条件，不能只在某一次 ready 消息中检查，造成按钮显示已准备却永久等候。重连可按产品规则保留同局准备意图；新局/明确取消则清理。清除粘住的按键与保留已确认动作基线分开处理，避免恢复后重复攻击。

### 大状态与测试预算

简单作品优先完整快照。需要增量时，以收件人已验证应用并 ACK 的基线计算；包携带局/代次/序号/基线身份，应用前校验，缺基线请求 full，周期性 full 提供恢复。hash、完整帧引用、大小与解压上限不能为减小包而放弃。latest 入队/发送成功不能充当应用 ACK。

发送/poll/资源传输分别计量。测试限额应复现真实 gate 的统计窗口、调用者粒度和合并规则；滑动分钟额度不能简单改成逐秒上限，加速模拟时钟不应改写真实配额时钟。失败或超时时也清理 room、轮询、等待器与定时器。

## 必须落成作品验收的路径

- **两个玩家视角**：双方实际按键，分别观察客人自己的角色和客人眼中的远端角色。采集最终场景根坐标/实际绘制提交，而非只看权威坐标、帧号或 FPS。旧大乱斗测试只操作房主，没覆盖客人自身回拉。
- **时延与过渡**：普通收包与抖动/成批到达两组；来源使用 180 ms SDK poll 延迟和预测测试的 300 ms 上行延迟，新作品按实际范围选用。验证持续移动、停止收敛、转向、跳跃/落地、恰好五次攻击或道具操作，以及瞬移/重生。记录逆向步、停帧比例、速度突增、输入至画面延迟；阈值随玩法制定，不能删除失败帧或放宽旧阈值制造通过。
- **恢复与资源**：短断线、重复重连、旧 epoch 消息、缓存丢失、双方已准备时断线恢复；统计形象传输次数与总字节。支持多人/晚加入的作品另测形象先于 hello 和中途加入，不因此扩展本技能双人 LAN 声明。
- **状态正确性**：恢复/再开/退出后继续真实操作，验证双方同一结果；用同序号的规范化状态/摘要对照，不能直接比较采样时刻不同的两个世界。平滑层采样前后规则状态应保持不变。
- **交付字节**：重建最终 HTML 并记录摘要，真实入口读取该文件。旧聊天附件/进行中对局固定旧字节；结束旧局后重新发送更新版。带探针的轨迹测试与无探针的最终产物检查分别报告。

为上述路径在作品项目登记具名专项与聚合门禁；宿主只保留通用加载、授权、SDK、收发和生命周期契约。真实 Electron 验证用隔离 userData/端口、首次绘制前隐藏、CDP 真键盘与后台截图；模拟网络、真实双实例、物理双机和公网证据分别注明。没有实际环境时列待验项，不援引作者的通过记录当成本次证据。
